# 🏦 NeoBank UI - Kotlin Multiplatform

> 🚧 **Estado del Proyecto: En Construcción (Fase de Arquitectura)** 🚧

Un prototipo de interfaz financiera ultra-premium (Neo-Banco) construido con **Kotlin Multiplatform (KMP)** y **Compose Multiplatform**. Diseñado para ofrecer una experiencia nativa de alta gama tanto en Android como en iOS con un solo código base.

## 🛠 Stack Tecnológico
*   **Lenguaje:** Kotlin
*   **UI Framework:** Jetpack Compose / Compose Multiplatform
*   **Arquitectura:** Clean Architecture (Feature-driven)
*   **Diseño:** Interfaz Dark Mode con elementos de Glassmorphism.
